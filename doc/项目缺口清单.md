## 二、后端缺失的 Controller

后端目前只有 10 个 Controller：`ad`、`comment`、`errorLog`、`feedback`、`notice`、`opLog`、`overview`、`thing`、`thingCollect`、`thingWish`。

### 2.1 缺失：`UserController`（影响最大）

前端有 10 个用户相关接口调用，后端**一个都没有实现**，全部会返回 404：

| 前端要调的接口 | 被谁调用 | 后端现状 |
|---|---|---|
| `/api/user/login` | 管理员登录页 | 缺失 |
| `/api/user/userLogin` | 用户登录页 | 缺失 |
| `/api/user/register` | 用户注册页 | 缺失 |
| `/api/user/detail` | 顶部导航、个人资料页 | 缺失 |
| `/api/user/updateUserInfo` | 修改资料页 | 缺失 |
| `/api/user/updateUserPwd` | 修改密码页 | 缺失 |
| `/api/user/list` | 后台用户管理 | 缺失 |
| `/api/user/create` | 后台用户管理 | 缺失 |
| `/api/user/update` | 后台用户管理 | 缺失 |
| `/api/user/delete` | 后台用户管理 | 缺失 |

**好消息**：`UserService` / `UserServiceImpl` / `UserMapper` 都是完整的（`getAdminUser`、`getNormalUser`、`createUser`、`getUserByToken` 等方法都在），**只缺一个 Controller 把接口暴露出来**，工作量和风险都不大。

### 2.2 缺失：`ClassificationController`

| 前端要调的接口 | 被谁调用 | 后端现状 |
|---|---|---|
| `/api/classification/list` | 首页分类栏、后台新闻表单、后台分类管理 | 缺失 |
| `/api/classification/create` | 后台分类管理 | 缺失 |
| `/api/classification/update` | 后台分类管理 | 缺失 |
| `/api/classification/delete` | 后台分类管理 | 缺失 |

影响：首页的分类筛选栏会是空的，后台发布新闻时选不了分类。同样地，`ClassificationService` 和 `ClassificationMapper` 都是现成的。

### 2.3 缺失：`OrderController`（遗留模块，建议直接忽略）

前端 `api/order.js` 里有 7 个订单接口，后端完全没有。这个项目是从「物品 / 订单」系统改造过来的，订单属于**没清理干净的残留**，路由里的 `admin/order.vue` 也是空壳。不影响新闻主流程。

## 三、前端缺失的 api 模块文件

这 4 个文件**被 import 但实际不存在**，会导致前端启动直接报「找不到模块」：

| 缺失文件 | 引用它的页面 | 是否需要马上补 |
|---|---|---|
| `web/src/api/user.js` | 登录、注册、个人资料、改密码、后台用户管理（共 7 处） | **必须补**，否则整个前端跑不起来 |
| `web/src/api/ad.js` | `views/admin/ad.vue`、`views/index/detail.vue` | **必须补**，两页都在路由里 |
| `web/src/api/log.js` | `views/admin/error-log.vue`、`login-log.vue`、`op-log.vue` | **必须补**，三个页都在路由里 |
| `web/src/api/tag.js` | `views/admin/tag.vue` | 可延后，该页面没挂在路由上，是孤立文件 |

> 后端的 `ad`、`opLog`、`errorLog` 接口都是齐的，所以补这几个前端文件只是「写请求封装」，改动很小。

---

## 四、结论与建议顺序

**当前状态：数据库通了，但项目整体还跑不起来。** 拦路的主要是前端 3 个缺失的 api 文件 + 后端 2 个缺失的 Controller。

建议按这个顺序修：

1. **补 `web/src/api/user.js`** —— 不补，前端编译都过不去
2. **补后端 `UserController`** —— 补完登录注册就能用
3. **补 `web/src/api/classification.js` + 后端 `ClassificationController`** —— 让分类功能活过来
4. **补 `web/src/api/ad.js`、`web/src/api/log.js`** —— 补齐后台广告和日志页
5. 订单模块（`api/order.js`、`admin/order.vue`）—— 建议直接删掉，属于遗留垃圾
